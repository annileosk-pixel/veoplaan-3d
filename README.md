# Mitut veovahendit on vaja? — 3D-laadimisülesanne

Interaktiivne harjutus kutseõppe logistikaerialadele: õppija jaotab terminalis ootavad
15 saadetist poolhaagistesse, laob need 3D-vaates lastiruumi ning arvutab iga auto kohta
kaalu, laadimismeetrid ning kaalu- ja mahutäituvuse. Harjutus kontrollib paigutuse ja
arvutused automaatselt ning annab kohe tagasisidet.

**Proovi brauseris:** https://annileosk-pixel.github.io/veoplaan-3d/

## Kasutamine

- **Brauseris:** ava ülaltoodud link. Tulemus kuvatakse lehel, kuid seda ei salvestata.
- **Moodle'is:** laadi SCORM-pakett (`veoplaan-scorm.zip`) üles tegevusena „SCORM-pakett".
  Tulemus läheb hinnetelehele ja ülesanne märgitakse sooritatuks alates 90 punktist.
